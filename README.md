🎬 MovieHub

A full-stack cinema booking web application developed as a portfolio project for practicing modern web development.

MovieHub provides a complete movie-ticket booking flow, from browsing movies and selecting a cinema/showtime to choosing seats, completing payment, and viewing booking history.

✨ Features

User Login / Register

Browse available movies

Select cinema

Select movie and showtime

Interactive seat selection

Booking summary

Payment flow

Digital movie ticket

Booking history

Responsive user interface

🚀 Getting Started

Clone the repository

git clone https://github.com/vollerball2548-spec/MovieHub.git
cd MovieHub

Frontend

cd frontend
npm install
npm run dev

Backend

cd backend
npm install
npm run dev

If your folder structure or start command is different, update the commands above to match the project.
